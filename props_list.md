## C. Интерактивное (отдельные узлы/файлы с понятными именами)

| Что | Где | Имя узла | Pivot |
|---|---|---|---|
| Входные двери домов | внутри каждого `house_*`, `old_town_hall` | `INT_door_*` | на петле, дверь открывается вращением вокруг Z |
| Окна для дефенестрации (ставни) | 2-й этаж каждого дома | `INT_window_*` (рама) + `INT_window_*_shutter_L/R` | на петлях ставен |
| Прилавки торговцев | `market_stall_produce/bread/pottery/cloth/empty.glb` | `INT_stall_*` + маркер `MARK_merchant` | центр основания; маркер — место торговца |
| Кузнец (прокачка меча) | `anvil.glb` | `INT_anvil` + `MARK_smith` | |
| Маркеры | везде | `MARK_*` — пустые узлы (Empty) | |

Также отдельно экспортируются `door_wood.glb` и `window_shutters.glb` — чтобы в Task 3 можно было ставить их где угодно.

## Свет для ночи
- Emissive-материалы: `M_WindowLit` (стекло окон), `M_Fire`, `M_LanternGlass`, `M_Coals`.
- Точечные источники (KHR_lights_punctual): фонари, факелы, вертел, горн. Узлы `LIGHT_*`.
- В игре (Task 5) интенсивность emissive и ламп умножается на «ночной» коэффициент.
