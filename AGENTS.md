# Заметки для агентов

## Референс-арты через ChatGPT (встроенный браузер)

Референс- и концепт-арты (персонажи, районы, пропсы, настроение сцены) можно заказывать у ChatGPT
во встроенном браузере Claude desktop (инструменты `mcp__Claude_Browser__*`). API и ключи не нужны:
используется обычный аккаунт пользователя, вход в ChatGPT в профиле встроенного браузера уже сохранён.

Порядок работы:
1. Открыть `https://chatgpt.com/` (`preview_start` с `url`). Если страница показывает «Войти»,
   попросить пользователя войти самому, пароль не вводить. На cookie-баннере выбирать «Сохранять только обязательные».
2. Кликнуть в поле «Спросить ChatGPT», ввести промпт, начинающийся с `Generate an image:`, и нажать Enter.
   Генерация занимает 30–90 с: ждать через `computer` → `wait` и проверять скриншотом.
3. Сохранение: навести на картинку, нажать иконку «Поделиться» в правом нижнем углу, затем **«Скачать»**.
   «Скопировать ссылку» не нажимать, она создаёт публичную ссылку.
   Перед скачиванием спрашивать разрешения у пользователя.
4. Встроенный браузер кладёт файл в `%USERPROFILE%\Downloads` под именем `<uuid>.tmp`. Это готовый PNG
   (проверить сигнатуру `89 50 4E 47`). Перенести его в `concept_art/` с осмысленным именем,
   например `prague_old_town_square_dusk.png`. В `concept_art/` лежит `.gdignore`, поэтому Godot эти файлы не импортирует.

Как приложить свою картинку к сообщению (референс, схему уровня), когда кнопки загрузки файла нет:
1. Положить JPEG размером до ~1 МБ в отдельную папку scratchpad и раздать её локальным сервером на `127.0.0.1` с заголовком
   `Access-Control-Allow-Origin: *`. Встроенный браузер localhost открывает.
2. Страница-«прыжок» на localhost делает `fetch` картинки и переходит на
   `https://chatgpt.com/robots.txt#claudefile=<имя>|<data URL>`. Это обязательно robots.txt, а не главная страница:
   если загрузить приложение ChatGPT с огромным якорем в адресе, оно потом не может отправить сообщение (`ERR_CONNECTION_CLOSED`).
3. На robots.txt через `javascript_tool` сохранить строку в `localStorage` и вызвать `history.replaceState`, затем перейти на `https://chatgpt.com/`.
4. Там собрать `File` из base64 через `atob` (`fetch(data:)` блокирует CSP), положить его через `DataTransfer` в
   `input[type=file][accept="image/*"][multiple]`, вызвать `change` и удалить ключ из `localStorage`.
   Перед отправкой дождаться миниатюры в поле ввода, потом ввести текст.

Что не работает (не тратить время):
- `fetch` или `<img>` со страницы ChatGPT на `http://127.0.0.1` блокируются CSP; `window.open` открывает адрес в той же вкладке;
- `navigator.clipboard.write` запрещён (`NotAllowedError`), а `ctrl+v` через `computer` не вставляет картинку из буфера Windows;
- вытаскивать картинку в base64 через `javascript_tool` слишком дорого (около 3 МБ PNG).

### Карта мира (вкладка Map)
`assets/ui/map_prague_painted.png` нарисована ChatGPT по обрезке плана-рендера (`concept_art/map/layout_ref.png`)
и выровнена под него через OpenCV ECC (affine), остаточная ошибка в пределах нескольких пикселей.
Картинка покрывает Godot X/Z-прямоугольник `MAP_PAINTED_RECT` из `blender/scripts/build_prague.py`
(он же `map.rect` в `prague_layout.json`). Если мир меняется: пересобрать план, обрезать, перерисовать, снова выровнять.
Проверка: `godot --path . scenes/game.tscn -- --tour map,x,z,yaw[,y]` сохраняет снимки вкладки Map со стрелкой игрока
в `renders/game/tour_N.png`.

Стиль промптов для этой игры: dark-fantasy action RPG, средневековая Прага около 1400 года, атмосфера в духе Gothic 1–2,
painterly, moody, gritty, факелы, туман, мокрая брусчатка, чешский лев на гербах; `wide cinematic 16:9`
для сцен, `full-body character sheet, front/side/back, neutral background` для персонажей; всегда `no text`.
Пример: `concept_art/prague_old_town_square_dusk.png` (Староместская площадь, рыцарь, лавка алхимика).
