# game-pipeline

A Claude Code plugin that teaches Claude a complete workflow for making 3D games, from concept art
to a deployed build, with every asset generated by code:

**ChatGPT concept art → Blender (Python, headless) → Godot 4 → Windows / Web / Android builds**

It is the process behind [Alchemists of Prague](https://severance.lol/4/), a Gothic 1–2 style action
RPG in medieval Prague: four districts in one open world, melee combat, day/night, trading, and
throwing enemies out of windows. About 10k lines of Blender Python build 101 glTF assets, and the
Godot game loads its levels from JSON that Blender writes.

## Install

```
/plugin marketplace add msveshnikov/alchemists-of-prague
/plugin install game-pipeline@alchemists-of-prague
```

Or copy `skills/game-pipeline` into `~/.claude/skills/`.

## Use

Just talk to Claude: "let's make a game about …", "write the style block and art prompts",
"order the concept art", "run task3", "add a new district", "repaint the in-game map", "ship it".
The `game-pipeline` skill loads when the request fits.

## What's inside

| File | Contents |
|---|---|
| `skills/game-pipeline/SKILL.md` | The pipeline at a glance, tools needed, principles, how to start a new game |
| `references/01-concept-and-prompts.md` | Design doc, the style block, prompt templates for locations, characters, UI |
| `references/02-task-templates.md` | task1–task5 templates (environment, characters, levels, population, Godot game), autonomous-mode rules, run 2 and stitching one world |
| `references/03-blender.md` | Procedural assets, naming conventions, textures, characters and skinning, levels, rebuild order |
| `references/04-godot.md` | Runtime level loading, UI as code, autotest and screenshot tours, exports |
| `references/05-chatgpt-browser.md` | Ordering art in the Claude desktop built-in browser, attaching your own images, aligning painted art to a level layout |
| `references/06-ship.md` | Finishing every task: commit, build all targets, deploy, verify |
| `scripts/align_to_layout.py` | Warp a painted image onto the layout render it was painted from (OpenCV ECC) |
| `scripts/chatgpt_upload/` | Local helper for attaching images to ChatGPT from the built-in browser |

## Requirements

- Claude Code desktop app (for the built-in browser) and a ChatGPT account signed in there
- Blender 4.2+ (built on 5.2), Godot 4.x (built on 4.7.2) with export templates
- Python 3 with `numpy`, `pillow`, `opencv-python` for the image helpers
- Optional: a web server reachable over `scp` to host the Web build and APK

## How it keeps AI-made games from being slop

- One style block in every art prompt, shared palettes and strict naming conventions.
- Everything 3D is procedural Python, so any asset rebuilds with one command and every fix is a code change.
- Claude must look at its output (renders, contact sheets, in-game screenshots) and compare it with the concept art.
- A self-playing `--autotest` and a vertical slice before scaling up.
- Every task ends with a shipped, playable build.
